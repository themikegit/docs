## Autentifikacija

Obe rute zahtevaju prijavljenu Clerk sesiju. Clerk middleware u `src/proxy.ts` štiti svaku putanju osim `/sign-in` i `/sign-up`. Pregledač automatski šalje kolačić sesije, pa linkovi unutar aplikacije rade bez dodatnih koraka.

Da biste pozvali rutu van pregledača, na primer pomoću `curl`, pošaljite Clerk kolačić sesije:

```bash
curl "http://localhost:3000/kpo?year=2026" \
  --cookie "__session=<clerk-session-token>" \
  --output kpo-2026.pdf
```

<Note>
  Interaktivni playground je isključen na ovim stranicama. Zahtevi sa sajta dokumentacije ne mogu da nose vašu invoicR sesiju, pa bi uvek bili neuspešni.
</Note>

## Osnovni URL

Koristite URL na kom radi vaša instanca aplikacije invoicR. Za lokalni razvoj to je:

```text
http://localhost:3000
```

## Server Actions

Kreiranje, izmena i brisanje podataka idu kroz Server Actions u `src/app/actions.ts`. Next.js ih poziva preko generisanih ID-jeva koji se menjaju sa svakim buildom, pa nisu stabilan API. Pogledajte [Server Actions](/sr/api-reference/server-actions) za ulaze i provere svake akcije.
